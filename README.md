# Biodata Webpage

A set of static HTML pages created as an early web-development assignment. The project demonstrates building structured documents with HTML, including a personal biodata page and a school timetable laid out with tables.

## Contents

`BioData51.html` is a personal biodata / resume-style page, and `SchoolTimeTable51.html` is a weekly school timetable built with HTML tables.

## Tech Stack

HTML

## Getting Started

Clone the repository and open either HTML file directly in your browser.

## Status

An introductory project built while learning the fundamentals of HTML structure and tables.
